Privacy Policy

App: Calculator Lock

Calculator Lock respects user privacy. This app is designed to provide calculator functionality and protect private photos, videos, audio, and other files directly on the user's device.

1. Information We Access

The app may request access to:

  • Photos, videos, audio, and other files selected by the user for import into the private vault
  • File or folder access, to allow users to import files, delete original files when requested, and move files to device storage

2. Information We Store

The app may store the following information locally on the user's device:

  • The user's vault PIN and security answer in Android-backed secure storage
  • Photos, videos, audio, and other files imported into app-controlled private storage
  • Vault metadata, folder names, file details, and generated video thumbnails
  • Basic app preferences needed to restore the app experience, including theme and list or grid view selections

This information is stored locally to support app functionality and convenience.

3. Information We Do Not Collect

At the current stage of the app, Calculator Lock does not require account creation and does not intentionally collect personal information such as:

  • Name
  • Email address
  • Phone number
  • Precise location
  • Payment information

The app is not designed as a social platform and does not provide public posting, public profiles, or public user content sharing.

4. How Data Is Used

Any locally stored data is used only to provide app features, including:

  • Authenticating access to the private vault and supporting forgotten-PIN recovery
  • Storing and organizing imported files in app-controlled private storage
  • Allowing users to preview images and videos and open supported files
  • Allowing users to move files between folders, move files to device storage, share, or delete private files
  • Restoring folders, file metadata, theme, and basic app preferences after reopening the app

5. Data Sharing

Calculator Lock does not sell user data.

The app does not intentionally share personal data with third parties except where required to support core platform behavior or app functionality, such as:

  • Operating system permission handling
  • User-initiated sharing actions using installed device apps
  • User-initiated opening of supported files using installed device apps

The app does not use advertising, analytics, cloud storage, or a backend service. Calculator and vault functionality operates locally without requiring an account or internet connection.

6. User Control

Users can control their data by:

  • Removing granted file or media permissions from device settings
  • Moving files between vault folders, sharing files, moving files to device storage, or deleting files from the vault
  • Changing the vault PIN after authentication
  • Clearing the app's local storage by uninstalling the app or clearing app data from device settings

Users should move important files to device storage before uninstalling the app or clearing app data. Uninstalling the app or clearing app data removes access to files that remain in app-controlled private storage.

7. Children's Privacy

Calculator Lock is a general-purpose utility app and is not directed specifically to children.

The app does not knowingly collect personal information from children.

8. Security

The app uses Android-backed secure storage for the vault PIN and security answer, app-controlled private storage for vault files and metadata, automatic vault locking, and screen-capture protection where supported. Reasonable care is taken to keep app data limited to what is required for the app's functionality. However, no method of electronic storage or transmission can be guaranteed to be completely secure.

9. Changes To This Privacy Policy

This privacy policy may be updated from time to time to reflect feature changes, legal requirements, or release updates.

If the policy changes, the updated version should be published at the production privacy policy URL before or together with the related app release.
